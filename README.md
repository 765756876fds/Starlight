# 星芒 (Starlight)

> **英雄联盟全能助手 × 本地/在线音乐聚合 × 多平台影视解析 × 极速语音交互**
> 一个基于 PySide6 打造的 Windows 桌面端娱乐与游戏辅助控制中心。

## 🌟 核心设计原则

1. **确定性优先**：写操作与关键业务全部由纯规则驱动。
2. **信息丰富，语音克制**：支持复杂的对局数据、影视榜单展示，但语音播报严格按照 SpeechJudge 分级（S/A/B/C/DROP），绝不啰嗦。
3. **故障隔离与并发安全**：模块间基于 EventBus/CommandBus 解耦，核心通信采用**物理双池隔离**与**独立打断旁路**，单链故障绝不拖垮全局。
4. **零配置迁移**：纯动态路径解析，绿色免安装，一键无缝迁移。

## 🚀 核心功能模块

### 🎮 游戏链 (LoL Runtime)
- **客户端深度集成**：自动接受对局、自动化选人/禁用、战绩一键查询。
- **实时对局数据**：基于客户端本地数据接口极速轮询，实时 KDA、经济、等级、装备追踪。
- **十人战绩分析**：在选人/加载阶段无缝获取双方十人段位、近期胜率、KDA 与“绝活”英雄。
- **修仙称号系统**：独家的 8 档“修仙”称号评判体系（基于胜率与 KDA 双维度）。
- **连招与提醒**：支持自定义英雄连招宏、敌方召唤师技能/装备动态 CD 提醒、目标计时与对局结束预测。

### 🎵 音乐链 (Music Hub)
- **多源聚合搜索**：基于开源插件协议（MusicFree / LX）的 JS 桥接，支持多平台在线搜索与高音质下载。
- **本地音乐库**：基于 `SQLite FTS5` 的极速检索，支持 ID3 封面与元数据读取。
- **Glass 沉浸式 UI**：纯自绘卡片网格，支持悬停动画与无边框玻璃质感（毛玻璃悬浮效果）。
- **桌面歌词**：独立透明悬浮窗，跟随播放进度同步，支持自定义字体/颜色/锁定穿透。
- **哼唱识曲**：基于 `AudioFP` 音频指纹算法，支持麦克风录制并匹配本地曲库。

### 🎬 影视链 (Movie Cinema)
- **多平台榜单**：内置豆瓣榜单与第三方热榜 Provider 架构，可扩展自定义榜单源。
- **资源站聚合**：支持标准的 CMS V10 接口，多源测速与自动切源 Failover。
- **内嵌秒播**：`--wid` 注入 Qt 容器，完美融合 mpv 的内嵌播放体验。
- **网页流本地解析**：集成开源解析库与 `ffmpeg`，支持通过网页链接直接提取真实视频流播放。

### 🎙️ 语音链 (Voice Assistant)
- **本地 ASR**：基于 `Qwen3-ASR` 本地大模型推理，毫秒级响应。
- **极速打断旁路**：物理隔离主 ASR 队列，采用**独立旁路 (Side-channel)**，在 TTS 播报时依然能 0.8 秒内极速响应“闭嘴/停止播报”指令。
- **拟真 TTS**：接入云端大模型 TTS 主力播报，保留本地/免费 TTS 作兜底。
- **纯规则意图**：毫秒级本地语义解析，拒绝 LLM 延迟。

## 🏗️ 软件架构

- **事件与命令**：`EventBus` (支持状态池/临界池物理隔离) + `CommandBus` (Fail-closed 中间件机制)。
- **状态管理**：`StateStore` 集中式管理，杜绝多线程共享可变对象引发的状态错乱。
- **任务调度**：自研 `Scheduler`，支持重入拦截、异步任务隔离与优雅停机。
- **路径解析**：`path_resolve` 统一收口，打包态与源码态动态适配。

## 💻 技术栈

- **语言**: Python 3.11
- **界面**: PySide6 (纯 QSS 手绘 + 玻璃拟物自绘组件)
- **播放引擎**: mpv (JSON IPC)
- **在线桥接**: Node.js + ffmpeg
- **游戏数据**: 官方 Client API + LCU
- **语音**: Qwen3-ASR + TTS
- **数据库**: SQLite (FTS5 全文检索 + WAL 并发模式)

## 📦 部署与打包

支持完整的自动构建与打包流水线：
- `build.ps1` 生成绿色便携版与完整性断言检查。
- `Inno Setup` 生成双版本安装包：
  - **轻量版** (首启自动下载模型)
  - **离线全量版** (内置模型，断网可用)
