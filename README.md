# Starlight · 星芒

音乐、电影、英雄联盟助手与本地语音控制，一个 Windows 桌面入口。

星芒把找歌、听歌、看本地影片、查看对局和语音操作整合在一起。保留游戏、音乐、电影、通知中心、设置五个主页面，让常用操作留在手边，执行结果说清楚。

**当前源码里程碑：`0.1.1.dev1`。这是开发版本，不是已完成安装验收的稳定发行版。** 本轮没有生成安装包；旧安装包不会自动包含这里的更新。[版本记录](CHANGELOG.md)列出了变化和保留问题。

## 主要能力

### 音乐：发现、搜索和播放连在一起

- 本地曲库扫描与搜索；通过 MusicFree/LX 兼容插件进行多源在线搜索。
- 推荐、排行榜、歌单、新歌、歌手/专辑及最近播放入口。只展示插件真正提供的内容；没有能力时显示空状态，不拿普通榜单冒充新歌。
- 播放队列可查看当前歌曲、指定下一首、追加和移除待播条目。顺序模式可安全调整待播顺序；随机模式不虚构确定的下一首，排序入口保持受限。
- 明确指定的下一首优先于随机选曲，连续指定 D、E 仍按 E → D 消费；重复歌曲按队列条目区分。
- 歌词、收藏与歌单、音量、循环/随机模式、九档倍速、高潮段跳转与手工标记、睡眠定时。
- 系统声音或麦克风短片段识曲：本地指纹匹配，以及通过 ShazamIO 接入的在线识别。本地库为空不会要求先建库才能使用在线识曲。

插件支持什么、当前网络能读到什么、某首歌能否实际播放，是三个不同问题。音源可能超时或返回不可用地址；搜索和目录会保留部分成功，并提供刷新/重试或换源建议。

### 电影：发现内容，也照顾本地影片

电影页内分为 **电影、电视剧、动漫、综艺、发现、本地影片**。首页给出有限预览、继续观看和最近添加；完整内容在分类内滚动、筛选，不把数百条榜单堆在首页。

- 添加本地影片目录、搜索本地库、选择本地视频，以及查看继续观看与播放历史。
- 本地电影正常停止、关闭播放窗口或退出应用前保存原生MPV播放位置，重新打开同一文件时续播；不会启动即自动播放上次电影。
- 同目录字幕发现与去重、手动加载SRT、字幕开关和轨道切换，保留Assrt入口。GBK自动转码尚未实现。
- 榜单海报单击查看详情，双击按真实片名搜索一次，**不自动播放**；由用户选择搜索结果/播放来源。
- 海报使用原始元数据及可信CDN，同一HTTP地址可升级为HTTPS；缺图有统一占位，短暂失败可重试。部分图片仍可能超时。

| 影视发现来源 | 当前接入情况 | 不代表什么 |
| --- | --- | --- |
| 哔哩哔哩 | 真实电影、电视剧、动漫公开榜单 | 不等于星芒可以直接播放榜单作品 |
| 爱奇艺 | 真实电影、电视剧、动漫、综艺公开榜单 | 不提供会员或DRM绕过 |
| 腾讯视频 | 真实分类热搜榜；官方动作按内容使用搜索入口 | 热搜名次不是播放授权或可用片源承诺 |
| 优酷、芒果TV | 目前保留官方观看/浏览入口 | 尚未接入自动结构化榜单，不伪装成数据来源 |

榜单数据、影片信息与实际播放来源分别标注。跨平台只在身份信息足够时合并；同名但年份、季数或地区不明的作品宁可并列。一个平台失败不影响本地库和其他来源。

### 英雄联盟：对局工作台与技能提醒

- 现有LCU/对局接入、客户端状态、玩家信息和游戏时间集中展示。
- 技能计时创建、查询与取消；常见英雄别名复用同一目录，已提醒但仍未到期的计时可以查询。
- 现有提醒与语音命令保持独立；新的语音反馈不会误取消普通游戏提醒。

真实客户端连接、重连和语音听感仍需分场景验收。仓库中的历史自动化入口必须显式开启并满足配置/阶段限制；本里程碑不新增自动锁英雄、聊天或连招能力，也不保证所有游戏操作可用。

### 语音、通知与双主题

本地Qwen3-ASR、VAD、中文规则路由和现有CommandBus负责语音输入到操作的衔接。支持有限参数追问，保留询问、否定和引用句的安全处理；识别不确定时不猜英雄或执行高风险操作。

| 想做什么 | 可直接尝试 |
| --- | --- |
| 音乐控制 | “暂停音乐”“继续音乐”“下一首” |
| 音量与速度 | “音乐音量五十”“倍速一点五倍” |
| 电影控制 | “暂停电影”“继续电影” |
| 技能计时 | “石头人闪现用了”“取消石头人计时”“查询当前技能计时” |
| 结束播报 | “停止说话” |

准备好模型和麦克风后，通过底部语音开关开启。没有统一唤醒词要求，建议一句一个明确操作。缺参可按界面追问补充，或说“取消”。更多说法见[语音说明](docs/语音控制说明与功能介绍.md)与[能力矩阵](docs/语音能力矩阵.md)。

- **通知中心**保留有限操作历史，同一次语音识别、执行与结果合并展示；技术字段继续留在日志中。
- **灵动岛式胶囊**展示当前聆听、识别文字、执行及结果，自动收起后仍可查看通知。
- **业务结果与播报结果分开**：音乐已暂停但TTS失败时，保留“已暂停”，再提示播报异常，不重复执行暂停。
- **日间/夜间主题**共用布局、即时切换并记住选择，默认夜间；队列、通知、播放窗口及相关独立界面同步适配。

ASR在本机运行不等于全部语音服务离线。Edge TTS依赖网络；Qwen TTS还需要个人授权密钥。主动开始在线识曲可能向第三方发送所选短音频，请只使用自己允许发送的片段。

## Windows运行环境

主要面向 **Windows 10/11 x64、Python 3.11**。PySide6范围以依赖清单为准，当前为 `>=6.6,<6.10`。

| 组件 | 用途 |
| --- | --- |
| MPV及配套文件 | 音乐、电影与TTS音频播放 |
| Node.js及桥接依赖 | MusicFree/LX兼容插件运行 |
| FFmpeg | 部分格式解码、识曲及媒体解析 |
| Qwen3-ASR模型、投影文件与llama-server | 本地语音识别；现有Vulkan路径和CPU回退 |
| 麦克风、驱动与系统录音权限 | 语音控制/环境音采集；系统声音使用WASAPI回环 |
| LoL客户端 | 仅游戏相关能力需要 |

Git源码不包含大型模型、播放器/Node/FFmpeg二进制、私人插件、音乐库、数据库或个人密钥。安装Python依赖不会自动补齐全部运行组件。

常用目录：

```text
models/
  Qwen3-ASR-0.6B-Q8_0.gguf
  mmproj-Qwen3-ASR-0.6B-bf16.gguf
third_party/
  mpv/mpv.exe
  node/node.exe
  ffmpeg/ffmpeg.exe
  llama/vulkan/llama-server.exe
  llama/cpu/llama-server.exe
```

配套DLL也需保留。模型缺失时现有启动流程可能尝试下载，不应把源码启动理解成完整离线安装。

## 从源码启动

在PowerShell中：

```powershell
git clone --branch a0-cleanup https://github.com/765756876fds/Starlight.git
cd Starlight
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
# 使用在线识曲时需要：
.\.venv\Scripts\python.exe -m pip install -r requirements-optional.txt
# 使用JS音源时，先准备Node与兼容插件，再安装桥接依赖：
npm --prefix app/music/online/js_bridge install
.\.venv\Scripts\python.exe main.py
```

首次配置可参考[安全模板](config/settings.example.yaml)，仅在目标不存在时复制：

```powershell
if (-not (Test-Path config/settings.yaml)) {
    Copy-Item config/settings.example.yaml config/settings.yaml
}
```

启动后先检查MPV，再按需要添加音乐/电影目录和插件；模型与麦克风就绪后再开启语音。个人API Key只保存在本机配置中。已有星芒运行时会唤醒原窗口，请先分清源码版与旧安装版，避免验证到另一份程序。

## 配置、数据与诊断

- 源码模式的多数可写数据以项目目录为基础；安装模式以 `%LOCALAPPDATA%/Starlight` 为主，具体位置以运行诊断为准。
- `config/settings.yaml`、API Key、Cookie、Token、播放历史和实际媒体库不应提交到Git。
- **根目录 `VERSION` 是程序版本的唯一来源**；Python、构建追溯和安装器模板读取它。旧个人配置中的 `app.version` 不覆盖程序版本，也无需重置配置。
- 设置中的诊断可查看源码/冻结运行方式、版本、构建信息和关键依赖。依赖加载成功不能代替实际播放、录音或在线识别。
- 分享日志前遮盖私人路径与凭据；技术日志保留在对应运行目录。

需要自检时可以生成一个新报告：

```powershell
$report = Join-Path $env:TEMP ("starlight-check-" + [guid]::NewGuid().ToString("N") + ".json")
.\.venv\Scripts\python.exe main.py --self-check --report $report
```

## 开发与验证

界面使用PySide6/QSS，统一ThemeManager和语义颜色；音乐/电影复用MPV与现有控制器，插件通过Node桥接；语音操作与播报队列分别反馈结果。异步请求有超时、缓存及代次保护，但忽略旧结果不等于撤回已经发送的网络/播放器操作。

开发者先阅读 [AGENTS.md](AGENTS.md)，按任务加载五个[项目Skills](.agents/skills)，维护证据集中在[PRODUCT_ROADMAP](docs/handoff/PRODUCT_ROADMAP.md)。不为了架构整洁重写已验收模块。

先安装pytest，再选择相关测试。以下命令关闭默认覆盖率/并行选项，避免生成 `.coverage`：

```powershell
.\.venv\Scripts\python.exe -B -m pytest tests/unit -o addopts="" -p no:cacheprovider
.\.venv\Scripts\python.exe -B -m pytest tests/ui/test_movie_card_interactions.py tests/ui/test_music_queue_view.py -o addopts="" -p no:cacheprovider
```

测试应使用隔离数据和配置。UI测试使用Qt事件循环/离屏平台；原生MPV集成测试需要已有Windows运行文件。Windows CI当前执行源码编译与 `tests/unit`，不代表全部UI、集成或真实设备通过。最新运行见[GitHub Actions](https://github.com/765756876fds/Starlight/actions)。

## 已知限制

- 用户反馈的**音乐偶发停止尚未完全定位**。本轮补充了MPV结束原因及下一首前后队列诊断，未宣称已解决，也未改写随机或插队算法。
- 海报URL丢失与永久失败缓存已修，但**图片仍可能超时，尚未完成全量加载验证**；腾讯电影榜最近一次有界检查未取得有效响应。
- 在线音源、TTS、在线识曲与公开榜单会受外部服务和网络影响；元数据成功不等于真实播放成功。
- 实际ASR文本、麦克风恢复、扬声器播报、LoL客户端重连、Windows原生对话框与多屏缩放仍需设备证据。
- LCU鉴权失效恢复有条件性风险，历史混合Qt挂起仍保留待复现，未借本次归档扩大修改。
- 本次Qt补测曾在测试清理阶段出现 `0xc0000374` 原生堆损坏；一次有界诊断复跑通过，原因仍未确定，不宣称已经消除。
- 主题和内容发现的新组合尚未完成新冻结程序与干净Windows安装验收；本页不提供未经核实的安装包或下载地址。
