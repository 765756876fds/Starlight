# Starlight 项目总纲

## 最终目标
Windows 桌面一体化助手：音乐 + 电影 + LoL + 全局语音控制。

## 当前阶段
统一语音语义层建设 + 音乐模块收尾。

## 模块边界
- 音乐/电影互斥，不能同时出声。
- 语音层不直接操作播放器，走 CommandBus → Controller。
- Feature Registry 为新功能接入入口。

## 路线图
- 阶段0：总纲台账建立（本任务）
- 阶段1：高优先级风险复核
- 阶段2：功能覆盖盘点
- 阶段3：缺陷修复
- 阶段4：语义层扩展
- 阶段5：新功能开发

## 当前优先级
P1：音乐/电影互斥复核、Feature Registry 接入 runtime
