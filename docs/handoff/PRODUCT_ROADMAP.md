# Starlight 产品维护记录

更新日期：2026-11-05。目标是少操作、真实反馈和可靠使用；本记录不是自动施工或发布授权。每轮只更新受影响条目，不把所有设想列入开发计划。

## 如何维护

- 状态分为：已实现、自动化支持、历史联网/用户验收、真实缺陷、条件性风险、待实机验证、待复现。
- 条目保留用户影响、代码/日志证据、最小下一步、依赖/风险和完成标准；修复并验证后转入已完成，不无限堆积旧任务。
- 没有新证据时不重新审计已收口能力；不把“能导入”“有数据”“离屏通过”分别夸大成联网、播放或实机成功。
- 最初建立本记录的批次仅新增规范与文档。后续修复以下各条目按实际施工更新；历史验证与当前验证分别记录。
