## 当前项目状态与维护优先级（2026-11-16）

本节是当前汇总；下方里程碑与实验记录保留当时事实，其中“本轮／最新／待验收”只对原日期有效，不作为当前待办。源码版本仍为 `0.1.1.dev1`，本次不改版本或安装包。

### 定位与技术路线

Windows 本地个人娱乐助手，以音乐、影视和已有游戏辅助为入口，追求轻量、安静、实用、可纠错。用户可用日常中文表达需求，结合真实播放器、当前页面、推荐队列、最近可靠操作和已确认习惯执行有限业务；不是通用聊天机器人。

语音能力审计与两轮本地语义实验已完成，评估过 Qwen3-Embedding-0.6B、Qwen3.5-0.8B、Qwen3-1.7B、Qwen3.5-2B Aggressive。正式路线为 **自研组合语义 → 实时情境决策 → 有界本地 SQLite 交互习惯 → 既有 CommandBus/业务控制器**。Embedding 仅作研究备用，不接入正式语义运行依赖，不新增常驻模型服务。语义层不加载 GGUF/LLM，不等于移除既有 ASR 模型。实验分数不作为产品实机成功率。

V1 已接通的业务：
- 自然暂停、恢复根据真实音乐/影视状态选择对象；无可靠对象、复杂陌生表达、冲突或破坏性模糊操作继续拒识或澄清。
- 音乐负面及一般评价可切歌，并将可追溯弱反馈绑定原歌曲；普通下一首不自动等同不喜欢。
- 明确喜欢与保存分离；“我喜欢的音乐”自动创建/复用，重复保存去重。
- “换个感觉”“来点不一样的”优先改变风格和榜单；没有可靠标签时只换不同榜单，不伪造情绪。
- 模糊影视推荐、可靠续播与稳定候选选择；评分/类型缺失时诚实降级，不自动播放未选择影片。
- 影片负面评价保存可靠进度、停止并展示替代候选；电影真正起播后暂停音乐，结束后不擅自恢复。
- 明确纠正可撤销可靠关联的弱反馈，不能覆盖更早的明确喜好；系统自行执行不算用户认可。
- 本地 `data/interaction_memory.db` 有界保存，沿正确用户数据目录；记录上限2000、写队列64，损坏/不可写安全降级，不保存原始录音。
