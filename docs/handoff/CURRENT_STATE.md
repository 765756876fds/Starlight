## 音乐业务实际能力与缺陷

- 个人音源是当前最新产品入口；普通入口不默认展示后台音源数量，右键高级入口才看全部候选。
- 搜索结果首批应快速展示；后台继续收集和比较资源，达到条件后**只自动重新排序一次**。当前实现仍可能在每个增量页重排，是待施工缺陷。
- 同一录音版本应合并，不同版本保留；当前聚合/替换有基础实现，但边界仍需真实使用复核。
- 音质应优先用户设置；目标档不可用时选最高可用；单曲明确指定档不可用要明确提示。播放品质与下载品质独立。
- 搜索界面不显示文件大小或模糊的“高档/超高档”；使用 MP3、FLAC、Hi-Res 等通俗标识。下载默认先给实际可用音质及对应大小。
- 沉浸歌词保留现有效果，后续增加逐字跳动；“文字特效”按钮应显示当前特效名称。
- 音乐设置需要整理；滚动失效等实际使用问题仍需解决。
- 支持兼容音源本地文件、网络链接添加，以及可靠更新/回退；音源精而互补，不追求数量。
