# 第24批音源授权与插件信任交接

本批以 `b17c2ec7f1cd90d34b12793d15c0011f39f6f864` 为基线。显式托管音源由宿主签发来源授权，绑定解析插件、实例及策略版本。授权对象只在内存中传递，下载台账保存可重建授权的来源与插件身份。默认插件宿主仍沿用第 22 批路径。

- 在 `OnlineSourceManager.register(source, lease=...)` 显式注入经过审查的来源绑定。播放、下载及恢复、下载附件和取词使用共有的 HTTP 目标、重定向、预算与取消机制。播放经现有本地代理转送到独立 MPV。
- `request_plugin_http` 是受控宿主的异步入口。调用方仍须绑定经过审查的插件进程，并在关闭、替换、策略撤销时停止旧会话。现有 Node 桥的自有请求未接入该入口。
- `PluginTrustStore` 接收固定包、可信策略及固定 Node，检查签名与完整文件清单。候选需要独立审查并明确启用，启用记录可以撤销。没有从可变远程更新入口自动安装或执行的流程。
- 托管榜单、发现、浏览和界面封面不发布插件原始地址。下载封面由显式授权的附件接口读取。申请正式启用前需验证用于界面的封面投影，以及受保护的安装目录、运行时依赖、独立宿主代码加载限制和撤销联动。
- 有界 HTTP 取消会等待请求上下文关闭。Windows 系统 DNS 的底层线程无法硬取消，实际占用仍计入现有 DNS 并发限制。短测已观察实际断连，长时间与真实公网矩阵留待隔离宿主验收。

外部验收记录包含受控 Windows MPV 完整播放、下载暂停及台账恢复、可信包回滚与撤销和本轮 Git 保护结果。
