# Starlight 2.0 — 已知问题清单

## 2026-11-27 · 搜索字段与回归边界

歌曲搜索的格式、品质与技术参数来自来源声明，字段缺失时保留未知。大小排序采用明确的候选完整字节数，未定义换算口径的大小不参与排序。各平台热度只在本来源内比较，缺少数据时停用该排序。

第17批保留了一次 MPV 停播重开返回 0 秒、预期 12 秒的完整集成失败和复跑记录。单次复跑通过不足以关闭该事件。共享 Node 进程的插件硬取消仍待单独验收。

## 2026-11-26 用户实际使用反馈

用户用分数作主观比喻，成熟播放器若为 70 分，当前星芒约为 50 分或更低。该比喻记录日常使用感受，尚无正式量表或对照样本。以下各项都待按相同插件、曲目、录音版本、档位和网络复现。

| 用户报告 | 恢复研发后的首项核验 |
| --- | --- |
| 下载选项看似齐全，部分档位实际不可用。 | 逐档比较插件声明、实际取址、下载与解码，并记录失败和降级。 |
| 下载前缺少可靠的大小、格式和实际可用音质。 | 分开记录声明、响应可提供的大小、容器与编码、最终写入结果，覆盖大小未知。 |
| 搜索结果只呈现少数来源，部分已安装音源没有明显出现。 | 核查加载、启用、搜索能力、调度、超时、过滤、聚合及 UI 展示。 |
| 有来源的榜单可播放，其搜索覆盖仍存疑。 | 同来源、同曲目分别走榜单直取和关键词搜索，对照能力、调用结果和展示。 |
| 曾取得约 200 MB、约 4 分钟的曲目，如今难找同类资源。 | 若用户提供许可样本，核对同录音、同版本、实际时长、精确字节、容器、编码和来源。体积只记录为观察值。 |
| 播放器能显示编码和位深，仍难找到和下载所需资源。 | 把“搜得到、播得动、下得到、结果说得清楚”分别验收，再查媒体参数准确性。 |

根因尚未查明。应用、插件、网络与服务是待取得证据的环节。历史隔离样片和 CI 的通过记录继续有效，适用范围见 [当前状态](CURRENT_STATE.md)。

## 2026-11-24 第十四批 · 影音稳定性基线

冷驱动缓存第一次创建发光程序仍约 13 ms，后续进程命中缓存约 0.23–0.47 ms。真实长测 GUI 心跳中位 16.02 ms、P95 17.71 ms、峰值 1130.15 ms。预热及最后十分钟的常驻内存中位为 384.16、413.98 MiB，采样程序同时保留测量数据，单次记录不足以判定增长原因。实体核显与游戏帧率余量待专项设备验证。

## 2026-11-24 第十三批补充 · 封面背景与构图

施工前实机在 Qt 先销毁 OpenGL 上下文后退出，曾访问已经删除的对象。此轮补上有效性检查，退出实录与定向用例通过。性能结论来自 RX 5700 单屏，其他驱动与可变刷新率未实测。

## 2026-11-24 第十三批歌词文字特效

本轮实机覆盖同一 RX 5700、固定 180 Hz 和三档 Qt 缩放。其他显卡、核显、远程桌面和游戏并行负荷仍缺实测。正常档首个原生着色器链接曾花约 48 毫秒，稳定播放的帧数据单独记录。真实 MPV 测试组一次在自然切歌后的 seek 断言超时，施工前与最终版原样复跑均为 14/14。

## 2026-11-24 第十二批渲染成本与音乐表现力

硬件合成增加工作集。本机 150% 强节奏样本结束时播放器工作集从约 302 MiB 增至 367 MiB，离开舞台约 3 秒会释放资源。结论来自 RX 5700 单屏实测，其他显卡、远程桌面和可变刷新率仍缺实测。混音 RMS、峰值和瞬态不能当作人声音高、情绪或可靠节拍。

## 2026-11-24 第十一批渲染复测范围

本机 180 Hz、100% 和 150% 的四个 12 秒窗口采样，歌词画面最长保持 22.22 毫秒。125% 另做真实窗口操作核对。Windows 可变刷新、多屏异刷和听音设备的物理延迟仍缺实测。普通 LRC 只提供行同步。此批接入可由现有适配器实际返回的增强 LRC 与 LX 字时间字段。

## 2026-11-24 第十批动态歌词范围

- 音量可视化依赖当前音乐 MPV 的带标签的 FFmpeg astats 滤镜。不可用时保留环境光。影院及减少动效模式无需启用滤镜。
- 第十批实测切换全局主题仍有短暂停顿。在 1160 逻辑像素窗口，切深浅主题到处理首轮绘制，施工前为 712 和 690 毫秒，施工后为 705 和 670 毫秒。此项与歌词播放帧耗时分开记录。
- 舞台对超过 160 个字符的单条歌词显示省略号，完整文本可在本句提示、辅助技术描述或「完整歌词」中读取。
- 本轮 Windows 单机有界采样覆盖 850 逻辑像素以及 125% 和 150% 缩放。4K、高刷新显示器、实际低端硬件、数小时持续播放及公网平台的输出时延仍需独立验证。

## 2026-11-24 媒体验收边界
