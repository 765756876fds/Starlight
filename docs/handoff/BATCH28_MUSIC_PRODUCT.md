# 第28批音乐使用路径收口

从左侧「发现音乐」进入歌曲搜索。普通入口没有可搜索的在线音源时，搜索结果提供「打开音源设置」，直达现有音乐设置及音源管理。“本地”可继续扫描、搜索和播放已有曲库。

有明确分页证据的来源继续使用「加载更多」。有结果、无结果、超时、连接失败和受控配置暂不可用分别显示。音源只提供通用失败类别时保留重试提示。受控入口的无可用来源提示引导核对既有授权和启动配置。

搜索结果区和异步播放曾共用同一个状态标签。新搜索现在拥有自己的反馈代次，先前播放的迟到信号不再覆盖它；播放器和旧播放请求仍沿原链路更新。自定义下载选定具体音质后，界面禁用仅用于自动选择的降级开关；现有后台按所选资源校验并反馈不可用。切换当前在线播放音质时，如果可用资源只满足更低档位，保留原版并明确提示。有已知回退的在线播放继续在音质菜单展示来源及实际编码。

实机使用正式 Windows Qt 主窗口、复用现有独立 MPV、隔离测试数据和自编签名样本。受控样本证明搜索、分页、选择音质、媒体解码、下载及暂停续传链路。普通入口另验收本地曲库、空在线入口和可达设置。历史第27批异常生命周期为本轮已验收基线；宿主、Job、IPC、profile 回收及授权策略代码未涉及本轮变更。

商业曲库、具体商业音源授权与受控配置的最终用户安装流程仍需各自的证据。维护建议从能稳定复现的分类提示和可靠启动证据开始。
