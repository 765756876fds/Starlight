## 使用方式

- 主窗口右上角「日间／夜间」切换按钮，文字表示将要切换到的主题。
- 设置 → 界面 → 主题：日间浅色、夜间深色。
- 即时生效，两个入口同步。默认夜间；重启读取原有用户配置目录下 `config/ui_prefs.json` 的 `theme`。

## 维护接口与颜色

`theme/colors.py` 的两份不可变 `ThemePalette` 是颜色来源，包含背景、三层表面、文字、边框、强调色、成功、警告、错误及 Overlay 等语义角色。浅色为暖白与浅灰，深色保留既有配色。正文及次要文字在三层实色背景上的对比度均有 AA 4.5:1 测试；这不代表所有图片、透明叠层均完成无障碍认证。

`theme/manager.py` 每个 QApplication 只有一个管理器。GUI 线程调用 `set_theme()`；后台调用 `request_theme()`，通过 Qt 排队信号切回主线程。切换会更新 QPalette、现有 Tokens 派生色和全局 QSS，并更新已打开窗口，不重建页面、队列或业务服务。

`theme/styles.py` 为已有内联样式绑定已知语义颜色，保留透明度和非主题色。新样式应直接使用当前 Colors／Tokens；不要缓存主题颜色到模块常量或状态对象。初始化和窗口显示处理历史样式，禁止全局拦截 Qt 的 StyleChange 过程。

图标使用 Qt 原生 QIcon 位图引擎和多尺寸缓存，切换时更新控件与菜单持有的图标。不要恢复本轮原型中的 Python QIconEngine：该路径在混合窗口销毁回归中出现过原生崩溃。

主题切换只改变外观，不发送播放、语音或游戏命令。实际视频保持黑色画布；封面、游戏图标及用户自选歌词颜色不强行换色。
