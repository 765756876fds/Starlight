## B．显式开启、关闭与请求归属

仅隔离测试入口执行如下程序化配置；不是面向用户的设置操作指南：

```python
adapter = GoalAdapter(isolated_controller, isolation_root=temporary_root, enabled=True)
trial = ListenMusicTrial(adapter)  # 默认关闭
isolated_runtime.bind_listen_music_trial(trial)  # 必须是同一个既有CommandBus
trial.set_enabled(True)
# 验证结束或需要退回旧入口：
trial.set_enabled(False)
```

- 只有原解析器已经识别为无参数 `music.recommend`，且本次文本精确为“我想听歌了”（允许句尾句号/叹号）的请求取得许可。没有扩展自然语言词库或安全优先级。
- 明确点歌、歌手、歌单、换榜单、换风格、下一首、暂停及非许可表达继续走原业务。非试验新指令即使发生在试验收尾中，也不会被新的忙碌判断接管；原控制器的用户操作代次负责取代旧目标。
- 每次有效新语音使旧ticket取消；手动操作、资源变化、关闭仍由原B4所有权和代次二次复核。许可只保存弱引用及代次，不存完整文本、歌名或路径。
- 同类试验请求已有在途操作时，不新开第二个适配器播放；关闭开关只取消ticket，不能撤销已经发出的IPC。收尾期间同一句目标请求会明确提示过期/收尾，而不是立即调用旧推荐器。
- `UNKNOWN_EFFECTS`不会触发自动旧推荐、自动重试或重建Adapter。重新开启仍保留原Adapter未决归属。收尾后，下一次明确、开关关闭的用户请求可以重新走原V1；这与失败自动回退不同。
