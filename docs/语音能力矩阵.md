# 语音能力矩阵（2026-10-30，当前源码）

每行示例都由 `test_voice_adversarial.py::test_capability_matrix_examples_match_real_parser` 调用真实规则校验。该校验只证明匹配结果；执行、状态与竞争边界另有测试，不代表真实设备验收。

共 65 行使用场景，对应 56 个不同意图值；状态查询、当前对局查询的多个参数和歌单的两种入口分行展示，不重复计为新的意图。

## 有条件的语义与缺口

- 裸“暂停/继续”保留全局暂停快照规则；明确对象只控制对应模块。参数追问只限音量、倍速、睡眠定时，12 秒内一次回复，跨域、取消、无关回复、过期后不继承。
- 有追问时“取消/算了/不用了/取消设置”返回 system.context_cancel，不删除其他提醒。
- VOICE_ENABLE、VOICE_DISABLE、TTS_ENABLE、TTS_DISABLE 只是常量，未发现完整语音规则与 handler 接线；语音入口仍用界面开关。关闭输入后也不能依赖语音重新唤起。
- 设置/诊断、本地视频文件选择、历史删除、字幕选择没有统一的语音业务入口，本轮保留界面操作。音乐当前曲目/播放状态虽有读取接口，未新增语音查询。
- 旧 alarm.spell 事件接线保留，但常用“某英雄技能用了”由 cooldown.start 优先接管；不能将两者重复计为两项独立功能。
- “清空歌单”旧别名实际清播放队列；“下一部”实际复用 next_episode。这两项涉及产品命名约定，本轮记录、不扩大为新的删除或搜片行为。
- 普通音乐/电影音量、跳转等旧接口的 None 不能一概解释为成功。部分 handler 仍缺完整协议确认，矩阵明确保留这一限制。
- 主 ASR 转写、语义与分发有 mock 链路测试；真实麦克风、TTS、在线源、LCU、键盘 hook 未在本轮实测。
