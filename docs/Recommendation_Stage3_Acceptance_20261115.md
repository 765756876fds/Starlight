## 队列观察项与轻量诊断

新增 `music_collection` 诊断：

- chart_read：榜单实际返回数量和最多50首保留数量。
- established：推荐回调完成后的实际队列数量、当前索引、模式与会话状态。
- loaded：区分推荐和普通在线单曲起播完成点。
- replaced/cleared：原在线榜单替换及用户清空的原因和数量。
- session_cleared/request_cancelled：明确停止、清空、切换内容或关闭时的会话/请求失效原因。
- next：手动或自然接续前的队列数量、位置和模式。

来源与榜单标识使用12位SHA256引用进行关联；不输出曲名、播放URL、令牌、原始ID、插件响应或配置。PlayQueue只增加持锁O(1)计数快照，不复制歌曲、不推进随机游标或历史。日志异常被隔离，不影响业务。诊断不建立第二套队列，不重建丢失集合、不增加轮询、线程或网络请求。
