## 能力与边界

[能力矩阵](语音能力矩阵.md) 包含 65 个使用场景、56 个不同意图，列出支持说法、参数、领域、业务入口、反馈和测试文件。没有为凑覆盖率新增业务能力。

- 未接线能力：VOICE/TTS 开关常量不等于完整语音功能；本地视频选择、字幕/历史管理、设置/诊断仍走 UI。音乐现有状态 getter 未新增语音查询。
- 命名约定待讨论：“清空歌单”实际清队列，“下一部”实际下一集。没有擅自变更删除或搜索行为。
- None 不是完整结果：在线音乐搜索仍不能区分“无结果”和“源失败”；部分跳转/音量旧接口没有协议确认。保留诚实的未知或无额外成功播报。
- 语音代次是全会话的，新识别指令（包括查询）会使旧搜索反馈过期；手动 UI 没有统一加入该代次。
- guard 只能阻止尚未开始的 handler、既有电影搜索检查点和未播报的反馈；已经发出的 HTTP/MPV 无法撤销。进入 movie.play、music.play_search_result 后仍有不可取消区间。出队有效性检查也不是事务，不能承诺取消已经进入 TTS 合成或播放的音频。
- 主 ASR 串行队列沿用现有机制；stop/start 代次丢弃晚到转写。两秒防重依据采样率与完整音频字节摘要，不按识别文本去重；不同录音可连续说“下一首”，同一音频两秒后仍可执行，不是通用回声消除。
